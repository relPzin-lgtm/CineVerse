Escolhi o **React** porque ele permite criar componentes reutilizáveis e atualizar as informações na tela sem recarregar a página, facilitando a criação de uma SPA.

## Tecnologias

- React
- JavaScript
- CSS
- Vite

## Como executar

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal.

## Como gerar a versão de publicação

```bash
npm run build
```

A pasta `dist` será criada com os arquivos do site.

As capas e os títulos são fictícios e foram criados para esta atividade. Os favoritos ficam salvos no navegador usando `localStorage`, sem cadastro ou banco de dados.

## Capas dos filmes

As capas são imagens promocionais dos filmes, carregadas pela internet a partir do TMDB. As sinopses são textos originais resumindo as histórias para fins acadêmicos. O CineVerse não é afiliado aos estúdios ou ao TMDB.
